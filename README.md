# mdohr.space

This is my personal website, built with [Astro](https://astro.build).  
It serves as my digital playground to share my projects, logs, and interests.

Originally, this website was based on the excellent  
[astro-developer-portfolio-template](https://github.com/devidevio/astro-developer-portfolio-template)  
by Dejan Vintonjiv, although it has since been heavily customized and now looks quite different.

## Features

- Custom terminal-inspired design
- Markdown-powered Captain's Log
- Minimalist layout with monospace typography
- Responsive and lightweight

Feel free to explore — it’s my little corner of the web!
